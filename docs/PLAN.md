# План и границы проекта

## Подтверждённые требования
- Android, Kotlin, Jetpack Compose.
- Локальный Qwen3-1.7B в GGUF Q4_K_M или Q4_0. Окончательный файл и совместимость runtime проверяются отдельно.
- Голосовой ввод с локальной транскрибацией; кандидат runtime — whisper.cpp.
- Локальная база знаний с поиском и сохранением заметок.
- Чтение календаря и запись после подтверждения пользователя.
- OpenCode CLI запускается из корня проекта в терминале Android Studio.

## Не определено
Модель телефона, RAM, версия ОС, minSdk, package name, точные версии библиотек, embedding-модель, размер базы, финальная Whisper-модель. Не выдумывать значения: сверить с проектом и пользователем.

## Последовательность
- [x] M0: аудит существующего проекта; чистая сборка, тесты и lint.
- [x] M1: минимальный UI чата и контракт движка с тестовым backend.
- [ ] M2: импорт GGUF, локальный llama.cpp-runtime, один запрос, отмена и освобождение ресурсов.
  Реализовано: llama.cpp, загрузка модели, генерация со стримингом, отмена, импорт/скачивание,
  удаление. Проверено на эмуляторе: загрузка, многоходовый контекст, скачивание и импорт
  через UI, «Стоп» (до и во время генерации), «Новый чат», история после перезапуска,
  генерация без сети. Открыто: реальное arm64-устройство, выгрузка модели через UI,
  release-сборка. Отчёт и инструкция: `docs/IMPLEMENTATION_REPORT.md`.
- [x] M3: запись аудио, whisper.cpp, транскрипция, редактирование текста перед отправкой.
  Реализовано: отдельный модуль `:whisper`, запись 16 кГц (fallback 48/44.1 кГц), лимит 60 с,
  отмена записи и распознавания, черновик при уходе в фон, вставка текста в поле ввода без
  автоотправки, скачивание/импорт/удаление модели, фильтр неречевых меток.
  Проверено на эмуляторе: ASR на фикстуре (точный текст), Qwen→Whisper→Qwen в одном процессе,
  скачивание модели через UI (проверка агента/рантайма), все состояния панели, отмена
  (3/3 PASS, 4888–5328 мс). Проверено пользователем вручную (микрофон хоста эмулятора):
  запись реального голоса, транскрипция, вставка в редактируемый черновик.
  Открыто: микрофон реального arm64-телефона, количественная точность на заданном наборе,
  явная отправка черновика в Qwen из редактора. Отчёт: `docs/IMPLEMENTATION_REPORT.md` §11–18.
- [ ] M4: локальные заметки: добавление, чтение, изменение и удаление через UI.
- [ ] M5: retrieval: выбор embedding/search, индексация, ссылки на исходные фрагменты, ответ при отсутствии данных.
- [ ] M6: чтение календаря с runtime-разрешениями и корректной обработкой времени.
- [ ] M7: структурированные команды LLM, валидация и подтверждение записи в календарь/базу.
- [ ] M8: измерение RAM и задержек на телефоне, ошибки, отмена, офлайн-проверка и регрессионные тесты.

Это дорожная карта, не разрешение на реализацию всех этапов. Перед каждым этапом согласовать критерии приёмки. Тесты и privacy-проверки добавлять по мере реализации, не откладывать до M8.
